# GFC

React + TypeScript web project powered by Vite.

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run build
npm run lint
```

## Design skill

The complete scroll-craft skill is installed at `.agents/skills/scroll-craft/`.
Read its `SKILL.md` before landing-page design or scroll-driven visual work.
Project guidance is recorded in `AGENTS.md`.
